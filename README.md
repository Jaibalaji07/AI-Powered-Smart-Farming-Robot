# 🌱 AI-Powered Smart Farming Robot

## 📌 Project Overview

The **AI-Powered Smart Farming Robot** is an intelligent agricultural system designed to assist farmers in monitoring crop health and improving productivity. This project integrates **Artificial Intelligence, Computer Vision, and IoT concepts** to detect plant diseases and support smart farming decisions.

The system uses a trained deep learning model (`leaf.pt`) to identify leaf diseases and provide real-time insights.

---

## 🎯 Objectives

* Detect plant diseases using AI
* Improve crop yield and health monitoring
* Reduce manual labor in farming
* Enable smart and automated agricultural practices

---

## 🧠 Technologies Used

## 🚀 Installation & Setup

### 🔹 Step 1: Clone Repository

```bash
git clone https://github.com/Jaibalaji07/AI-Powered-Smart-Farming-Robot.git
cd AI-Powered-Smart-Farming-Robot
```

### 🔹 Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### 🔹 Step 3: Run the Project

```bash
python main.py
```
